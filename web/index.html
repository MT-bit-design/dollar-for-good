    Rules we never break

    • Every number has a source link, a date, and the exact quote it came from. If the number isn't in its own quote, we don't use it.
    • If we can't source a number, it is marked missing. We never guess.
    • All math is done by plain code. The AI model only finds and quotes; it never calculates.
    • Website text is untrusted. The agent is told to ignore any instructions inside pages, and our code rejects any quote that isn't word-for-word on a page it actually fetched.
    • Each research run has hard caps on model calls, page fetches and tokens, plus a daily token budget.

    Read the caveats

    Estimates come from different evaluators, years and methods. Climate advocacy estimates are highly uncertain expected values. Use the ranking as a starting point for questions, not a final verdict.
